# Testes de logicas e algoritimos

Esta pasta guarda os pequenos projetos e scripts que criamos para testar a lógica de programação, condições e álgebra booleana.

## 📂 O que tem aqui dentro?

* **`cafe.py`**: Um script em Python que testa o uso de entradas do utilizador (`input`) e condições encadeadas (`if/else`) para simular uma máquina de café.
* **Testes da Loja Online**: Experiências em JavaScript para validar regras de negócio, como descontos e validação do carrinho.

## 🚀 Como executar os testes

Para correr o teste do café, abra o terminal nesta pasta e digite:
`python cafe.py`
